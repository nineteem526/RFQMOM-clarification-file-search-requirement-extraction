设置

模型与接口

配置用于当前项目问答和检索的模型与接口，支持对接企业自有模型或第三方服务。

用于生成问答结果的语言模型，需具备较强的工程专业理解与指令遵循能力。
用于将文档和问题编码为向量，影响检索的语义匹配效果。
结合语义相似度和关键词匹配，提升工程文档的检索召回率与准确性。
仅返回相似度不低于该阈值的文档，取值范围 0.30 - 0.95。
每次检索返回的候选文档数量，范围 3 - 50。
启用后，可对扫描件、图片类文档进行文字识别并纳入检索。
仅在本项目资料获准发送时启用。当前问题和检索片段将发往已批准的企业端点。
当前项目独立数据库、文档原件及索引存储目录（不同项目完全隔离）。

检索参数

微调当前项目库的切分粒度与混合检索召回策略（供后续 P1–P5 后端优化联动）。

工程文档推荐 380–512 tokens，避免跨条目切断技术参数。
相邻文本块保留重叠上下文，减少跨段条件漏召回。

文档解析说明

系统支持 PDF、DOCX、XLSX、TXT、MD 等常见工程文档本地解析，不向外部上传原件。

• 原件隔离：每个项目拥有独立目录与独立 SQLite 数据库，互不串库。

• 核对边界：复杂跨页表格、CAD 图纸及扫描件 OCR 结果请务必结合原件复核。

数据与备份

为当前项目数据库与上传原件创建一致性 ZIP 备份存档。

点击右侧或下方“创建备份”即可打包当前项目独立数据库与文件快照。

关于系统

《基于检索增强生成的工程询价文档智能处理系统设计与实现》

• 支持多项目独立数据库隔离管理与一键切换。

• 面向 RFQ 询价文件、技术协议、澄清文件、会议纪要及参数表提供智能问答、原文溯源、双栏对照与结果导出。

• 生成结果仅供工程师人工审核，不代替技术批准或合同判断。
